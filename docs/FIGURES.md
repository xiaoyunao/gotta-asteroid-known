# Figure Notes

All figure products are generated from the filtered GOTTA-only table `gotta_asteroids.fits`.

## `outputs/known_object_processing.png`

Workflow diagram for the known-asteroid processing chain. This file was added manually and is tracked as an output asset.

## `outputs/asteroid_orbits.png`

Orbital-element distribution of known asteroids detected by GOTTA.

- Input: `gotta_asteroids.fits`
- Script: `scripts/plot_gotta_asteroids.py`
- Columns: `orbit_elements_a`, `orbit_elements_e`, `orbit_elements_i`, `object_orbit_class_name`
- Panels:
  - semimajor axis vs eccentricity
  - semimajor axis vs inclination
- Style: kept identical to the original `asteroid_orbits` plotting format.

## `outputs/gotta_radec_healpix_nside64.png`

Sky distribution of GOTTA known-asteroid detections in RA/Dec.

- Input: `gotta_asteroids.fits`
- Script: `scripts/plot_gotta_asteroids.py`
- Columns: predicted ephemeris `ra`, `dec`
- Method: HEALPix binning with `nside=64`, plotted in a Mollweide projection
- Color scale: logarithmic counts per HEALPix pixel, clipped at 100 counts per pixel for readability
- RA tick labels are manually placed near Dec = -15 deg and include degree symbols to match the Dec labels.

## `outputs/gotta_stats.json`

Machine-readable statistics generated by `scripts/summarize_gotta_asteroids.py`.

The human-readable version is `docs/GOTTA_STATS.md`.
